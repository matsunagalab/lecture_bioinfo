第04回はAttentionの模型、ESM-2による穴埋め予測、文脈の比較を観察します。モデルの準備が進まない場合は、Notebookの保存済み出力を使う設定、または計算済み出力HTMLを利用できます。HTMLはファイルをダウンロードし、ブラウザで開いてください。SCORM ZIPはWebClassなどの学習管理システムへの登録用です。

教材内の引用・出典を参照してください。引用図・第三者のコードの権利は各権利者に帰属します。第03回の3D表示には3Dmol.jsを同梱し、[ライセンス](03_%E3%82%BF%E3%83%B3%E3%83%91%E3%82%AF%E8%B3%AA%E6%A7%8B%E9%80%A0%E3%81%AE%E5%9F%BA%E7%A4%8E/3Dmol-LICENSE.txt)を掲載しています。

第05回はColabFoldでユビキチンを予測します。T4 GPUを選び、上から実行してください。2026年10月11日にT4で予測5モデル・3D表示・信頼度グラフ・結果ZIPの保存まで確認しました。GPUの割り当てや待ち時間は利用状況によります。ColabFoldのコードは[ライセンス](05_AlphaFold2%E3%81%AB%E3%82%88%E3%82%8B%E6%A7%8B%E9%80%A0%E4%BA%88%E6%B8%AC/ColabFold-LICENSE.txt)を参照してください。

第06回はBoltz-2でタンパク質と低分子の複合体を予測します。T4 GPUを選び、全セルを実行してください。2026年10月11日に予測・信頼度グラフ・3D表示・結果ZIPの保存まで確認しました。初回準備から予測完了まで約6分でしたが、GPUと回線により変わります。授業用に反復数を減らした設定です。コードの[ライセンス](06_Boltz%E3%81%AB%E3%82%88%E3%82%8B%E8%A4%87%E5%90%88%E4%BD%93%E6%A7%8B%E9%80%A0%E4%BA%88%E6%B8%AC/Boltz-LICENSE.txt)を参照してください。
