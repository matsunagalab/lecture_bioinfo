# 生命情報工学特論

埼玉大学・2026年度の授業で新たに作成・改訂した学生向け教材です。準備できた回から追加します。

## 第04回の演習を開く

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/matsunagalab/lecture_bioinfo/blob/main/04_%E7%94%9F%E5%91%BD%E7%A7%91%E5%AD%A6%E3%81%AE%E8%A8%80%E8%AA%9E%E3%83%A2%E3%83%87%E3%83%AB/%E7%AC%AC04%E5%9B%9E_ESM2%E3%81%A7%E9%85%8D%E5%88%97%E3%82%92%E8%AA%AD%E3%82%80.ipynb)
