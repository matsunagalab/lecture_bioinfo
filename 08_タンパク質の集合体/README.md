## 既存資料の再利用（2026-10-11改訂）

2021年セミナーのカプシド・正二十面体・準等価理論、2024年4月の接合点・ドッキング、2024年6月の120量体とサブユニット比較、2025年6月の形状分類、2025年12月のタイリング解析を再利用。tauは2025年認知症学会の疾患別構造、研究の動機、ProteinMPNNとColabDesignの結果、実際の無固定設計配列を主軸にした。培養細胞・マウス・電子顕微鏡の結果は別条件のMutant39であり、演習のTYL配列の実験ではないと本文・ノートで区別。pLDDTを熱力学的安定性とする旧文言を訂正し、エネルギー地形は研究の目標を表す模式図と明記。 本編38枚中31枚、付録を含む62枚中54枚に既存スライド・図を使用。
