昨年度「分子シミュレーションの準備」の結合・角度・二面角・非結合相互作用の分子模型、溶媒の箱、エネルギー準位と温度の図を再利用。古いEquation.3オブジェクトは元の数式画像へ変換してPowerPointでの修復エラーを解消。個々の微視的状態と状態群の確率を区別する説明を補足。 本編39枚中21枚、付録を含む54枚中35枚に既存スライド・図を使用。


## 2026-11-22 図の縦横比と説明の改訂
